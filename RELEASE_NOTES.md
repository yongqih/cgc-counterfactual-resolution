# Package contents

The package supports five main figures, three Extended Data figures and four supplementary figures.

- T-cell response construction, leave-one-donor-out prediction and response decomposition.
- State evaluation across cytokine and drug perturbations.
- Tahoe entrywise completion, response resolution, pathway fidelity and gene-selection controls.
- LCL full-gene and response-program prediction, independent reprocessing and representation controls.
- Patient-disjoint organoid drug ranking and RNA representation analyses.
- LARRY paired-error bounds across 21 clones, with cell-bootstrap and culture-family sensitivity analyses.
- CellTag-multi six-fate prediction, marginal and fate-conditional calibration, and matched-information comparisons.

Execution commands are in `REPRODUCIBILITY.md`. Numerical sources for each panel are indexed by `source_data/CURRENT_PANEL_MAP.csv`.
